# ماذا عن structure ال documentation خلال هذا التطبيق

  >للتسهيل سوف يتم كتابه ال documentation بلغه مفهومه لاي حد بيكتب عربي و بيفهم برمجه عمتا بحيث هيكون فيه كلام انجليزي وفي نهايه كل ملف من ال documentation هيكون في نسخه مترجمه بعني التطبيق هيكون كdocumentation مكتوب مرتين مره عربي و ديه هتكون مثابه prompt  للترجمه من للذكاء الصناعي من اجل الترجمه
